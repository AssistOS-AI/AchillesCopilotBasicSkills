Skill reference

DGSkill Build

Defines adaptive request-local skills that answer directly or generate temporary guarded JavaScript.

Operational contract

The skill requires an explicit decision between textual and procedural output, a bounded prompt, sandbox policy, and normalized results. It is intended for exploratory or one-off work that does not justify a stable generated module.

Local artifacts

  • SKILL.md defines execution modes and guardrails.
  • DS.md summarizes the dynamic execution boundary.
  • skill.json declares aliases, dependencies, and the dgskill.md output.

Dependencies and outputs

Declared dependencies: gamp-specs, achilles-specs

The descriptor and catalog metadata define the outputs for this skill. Consumers must preserve the complete folder when copying it so referenced files and examples remain available.

Maintenance invariant

Generated code is transient, scope remains request-local, and sandbox and normalization rules are explicit.

See DS005 for the authoritative skill contract.
