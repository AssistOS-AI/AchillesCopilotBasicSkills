Skill reference

C-Skill Build

Defines specification-driven, code-backed skills with stable descriptors and generated JavaScript implementations.

Operational contract

The contract keeps routing, input, output, and hard constraints in cskill.md, places deeper module requirements in specs/, and treats src/index.mjs or src/index.js as the executable action(args) entrypoint.

Local artifacts

  • SKILL.md defines descriptor and source-layout rules.
  • DS.md records the separation between contract, specification, and generated implementation.
  • skill.json declares expected outputs and dependencies.

Dependencies and outputs

Declared dependencies: gamp-specs, achilles-specs

The descriptor and catalog metadata define the outputs for this skill. Consumers must preserve the complete folder when copying it so referenced files and examples remain available.

Maintenance invariant

Descriptors and module specifications remain authoritative when executable code is generated or regenerated.

See DS004 for the authoritative skill contract.
