Skill reference

Achilles Skill Builder

Defines the descriptor, layout, discovery, and execution contracts for every AchillesAgentLib skill family.

Operational contract

The skill selects among cskill, oskill, dcgskill, tskill, Anthropic-style SKILL.md bundles, and dynamic Ploinky agent skills. It specifies recognized sections, entrypoints, allowlists, session types, generated-artifact boundaries, and the plain-text result contract used by the runtime.

Local artifacts

  • SKILL.md contains the complete family reference and authoring checklist.

Dependencies and outputs

Declared dependencies: None declared.

The descriptor and catalog metadata define the outputs for this skill. Consumers must preserve the complete folder when copying it so referenced files and examples remain available.

Maintenance invariant

The descriptor filename determines the family, AgentLib-native descriptors use only recognized sections, and dynamic Ploinky agent skills are exposed only through oskill Allowed Agents.

See DS002 for the authoritative skill contract.
