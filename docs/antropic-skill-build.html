Skill reference

Antropic Skill Build

Defines the self-contained portability baseline for Anthropic-style SKILL.md bundles.

Operational contract

The skill keeps instructions, references, templates, assets, and helper modules inside one portable skill folder and treats repository-wide conventions as authoring guidance rather than runtime imports.

Local artifacts

  • SKILL.md defines portability directives.
  • DS.md summarizes the design boundary.
  • skill.json declares aliases, dependencies, outputs, and entrypoints.

Dependencies and outputs

Declared dependencies: gamp-specs, achilles-specs

The descriptor and catalog metadata define the outputs for this skill. Consumers must preserve the complete folder when copying it so referenced files and examples remain available.

Maintenance invariant

A copied skill must retain everything it needs except capabilities supplied by the agent runtime itself.

See DS003 for the authoritative skill contract.
