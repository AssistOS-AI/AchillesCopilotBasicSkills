Skill reference

O-Skill Build

Defines declarative orchestrators that coordinate bounded sets of skills and Ploinky agents.

Operational contract

The descriptor separates optional preparation from main instructions, declares preparation and execution allowlists, optionally exposes Allowed Agents, and selects loop or soplang session behavior according to workflow branching needs.

Local artifacts

  • SKILL.md defines the orchestration descriptor contract.
  • DS.md summarizes the bounded coordination model.
  • skill.json declares dependencies and the oskill.md output.

Dependencies and outputs

Declared dependencies: gamp-specs, achilles-specs

The descriptor and catalog metadata define the outputs for this skill. Consumers must preserve the complete folder when copying it so referenced files and examples remain available.

Maintenance invariant

The orchestrator’s reachable capabilities are explicit, preparation remains separate from execution, and domain work is delegated to allowed skills or agents.

See DS006 for the authoritative skill contract.
